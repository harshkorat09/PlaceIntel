# 1. Project Overview

PlaceIntel is an AI-powered Placement Intelligence Platform developed to modernize the campus placement process by combining placement management with Artificial Intelligence.

Unlike conventional placement portals that only display company information, PlaceIntel provides intelligent insights, personalized recommendations, semantic search, and AI-assisted guidance to help students prepare for placements effectively.

The system centralizes placement information, maintains structured company and student data, and integrates an AI-powered chatbot capable of answering placement-related questions using Retrieval-Augmented Generation (RAG).

The project follows a modern monorepo architecture using React, Express, FastAPI, PostgreSQL, Prisma ORM, Docker, and OpenAI technologies.

---

# 2. Vision

Our vision is to build a centralized placement intelligence platform that transforms raw placement data into meaningful insights for students, faculty, and placement coordinators.

The platform aims to become an intelligent assistant that not only stores placement information but also helps students make informed career decisions through AI-driven recommendations.

---

# 3. Problem Statement

Most college placement systems suffer from several limitations:

- Static placement notices
- Poor search capabilities
- Lack of personalized recommendations
- No AI assistance
- Difficulty comparing companies
- No centralized knowledge base
- Manual eligibility verification
- Limited analytics

Students often spend significant time searching through multiple documents and notices to understand company requirements, eligibility criteria, and preparation strategies.

Placement coordinators also face challenges in managing placement drives, updating information, and providing personalized guidance.

---

# 4. Motivation

Artificial Intelligence has significantly improved information retrieval and recommendation systems across various industries.

However, many educational institutions still rely on traditional placement portals that lack intelligence and personalization.

The motivation behind PlaceIntel is to bridge this gap by introducing AI-powered placement assistance while maintaining a scalable and maintainable software architecture.
