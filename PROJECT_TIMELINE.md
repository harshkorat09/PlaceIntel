# PlaceIntel project timeline

1. Foundation: configuration, Prisma migrations, error handling, project modules.
2. Identity: login, password hashing, JWT middleware, student/admin roles.
3. Catalogue: company, placement, branch, skill, and attachment management.
4. Discovery: placement list, search, filters, pagination, and detail page.
5. Eligibility: student profile, deterministic eligibility checks, Fit Score explanation.
6. Analytics: placement counts, package summaries, branch and skill breakdowns.
7. Chatbot: notice extraction, chunking, embeddings, retrieval, grounded responses, source metadata.
8. Release hardening: tests, security review, logging, rate limits, backups, and deployment.

Each phase should include implementation, tests, updated seed data, and documentation.
