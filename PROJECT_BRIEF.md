# PlaceIntel project brief

PlaceIntel is a CHARUSAT placement intelligence platform. It structures placement notices and company information so students can search opportunities, understand eligibility, view an explainable Fit Score, and ask grounded questions. Administrators maintain companies, placements, eligibility rules, and source notices.

## Current implementation

The repository currently contains React/Vite web scaffolding, an Express API health endpoint, a FastAPI chatbot placeholder, Prisma/PostgreSQL schema and seed data, Docker Compose services, shared TypeScript contracts, and local upload storage.

## First release

Authentication, role-based authorization, company and placement management, student search and filters, eligibility evaluation, explainable Fit Score, statistics, notice attachments, and evidence-grounded chatbot responses.

## Important limitation

Business routes, full UI pages, chatbot retrieval, and production deployment are planned work. See the module implementation documents beside each service.
